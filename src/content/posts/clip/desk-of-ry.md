会話型の UX と音声 AI の仕事を 7 年続けてきたプロダクトデザイナー、Ryan Haigh さんの個人サイト「Desk of Ry」です。まんなかに、落ち葉の散る間仕切りの中で本人がキーボードを打っている机の絵があり、机の上のランプや引き出しを押すと、それぞれ動きだします。下には、つくったものの「Side Quests」と、AI エージェントにわたすスキルの「Authored Skills」が並ぶ。机の人は Google の Nano Banana Pro で描いて Veo 3.1 で動かしたもので、マイクで話しかけられる RyBot の姿にもなっています（いまは音声の仕組みを移している途中で、話せません）。

絵に描いた机なのに、ランプは手に取って回せて、引き出しからはおもちゃがこぼれてくるのがたのしい。

## キーボードを打つ机の動画

机の人は、状態ごとに分けた透過の動画を重ねて切り替えています。ふだんはキーボードを打つ動画をループさせ、20 秒ほどおきに、のびの動画とコーヒーの動画を交互に差しこむ。差しこむのは、打つ動画のループの終わりまで 0.22 秒を切ったときで、そこから 200 ms で重ねて替えるので、ループの継ぎ目で替わります。

昼と夜の机は同じ組み合わせの動画を持っていて、見えていないほうのテーマの動画も、並べて再生しつづけている。250 ms ごとに見えているほうと比べて、0.15 秒を超えてずれたら再生位置を合わせ、それより小さなずれは再生速度を 1.04 倍か 0.96 倍にして詰めます。

夜に替えても、本人が昼の続きの手つきのまま打ちつづけているのがいい。

## 机の上のものを押すと開く 3D の窓

ランプ、カードを立てるデスクオーガナイザー、ペナントは、机の動画の上に、1920×1080 の座標で輪郭をなぞった SVG の path を重ねて当たりにしています。押すと窓が開き、選んだものの glb を three.js で回せる。窓の 3D は、テクスチャを長いほうの辺が 128 px（ペナントは 256 px）になるまで縮めて、ニアレストネイバーで拡大しているので、画素の粗さがそのまま見えます。そのうえで、ライティングしたあとの色を 4×4 のベイヤー行列で組織的ディザリングして、各チャンネル 8 段階に減色している。ディザの網目は CSS の 1 px ごとに置いてあるので、高精細な画面でも網目が細かくなりすぎません。

ランプとオーガナイザーは、投影したあとの頂点を、画面の 1.25 px ごとの格子にスナップしていて、回っているあいだ、頂点は 1.25 px きざみでしか動きません。ペナントのほうは、頂点を 3 つの正弦で小さく揺らしています。

窓のうしろの色は、テクスチャを 32×32 に縮めて、黒と白に近い色をのぞいた画素から選んでいます。彩度の高い色ほど重くして近い色どうしをまとめ、重みの合計がいちばん大きいまとまりの平均の色を、グレーと混ぜてグラデーションにする。ランプを開くと、窓のうしろはランプの緑に染まる。

机の上のものが、減色した昔のゲームのような見た目で手元に来るのが、おもしろい。

## 引き出しからこぼれるおもちゃ

引き出しにカーソルを乗せると、引き出しが開くところの 25 コマを 5×5 に並べた画像から、コマを canvas に描き替えて開きます。押すたびに、three.js と剛体の物理演算で、魚、イノシシ、一つ目の小さなフィギュアの中から 3 体が飛び出す。

物理の世界は絵の画素をそのまま単位にしていて、カメラも、水平から 30 度見下ろす向きの平行投影にして、縦横 2:1 のアイソメトリックで描いた机の絵に合わせてあります。床には、ラグの厚みと、引き出しの台、椅子、本人の脚、靴のまわりを見えない箱として置いてあるので、おもちゃは絵の椅子や脚に当たってはね返る。さらに、机の前板と側面、天板、靴、椅子と本人の輪郭を絵の座標でなぞって 3D の面にし、色は書かずに深度だけを書いています。うしろへ転がったおもちゃは、絵の椅子や机のうしろに隠れる。

おもちゃの明るさは、1 体ずつ CPU で計算しています。ラグの縁にいるか、椅子や本人の箱の影に入っているか、ランプの光が届くかを求めてインスタンスの色の 3 つのチャンネルに入れ、シェーダーで、半球光、平行光源、ランプの点光源の強さにそれぞれ掛ける。夜にするとランプの点光源が点き、ランプのまわりに転がったおもちゃが照らされます。

絵の上に、物理で動く 3D のおもちゃを、奥行きまでそろえて重ねてあるのがすごい。

## 右上のボタンで夜にするところ

昼と夜の切り替えは、夜の紺の上に昼の地の色の層を重ね、その層のマスクを毎フレーム SVG で描き直してつくっています。マスクの形は点を並べてつくったスーパー楕円で、大きいときは指数 4.5 の角の丸い四角、小さくなるにつれて指数 2 の円に近づく。輪郭には 3、5、7 山の正弦を重ねて波打たせ、その揺れの大きさに、始めと終わりで 0 になる sin を掛けているので、画面いっぱいのときと閉じきるときは、ゆがみのない形になります。形は強くぼかし、縁にだけ細かい粒の模様をかける。全体は 2 秒の 5 次のイーズアウトで進み、途中でもう一度押すと、いまの位置から引き返します。1 フレームで進める時間は 50 ms までにしてあって、ブラウザが詰まっても、形は先へ飛ばずにその場で待つ。Safari とスマートフォンでは、この波は出ず、1.5 秒のクロスフェードで替わります。

机の明るさは、経過時間ではなく、波の形から決めています。机の絵の上に 5×5 の 25 点をとり、それぞれが形の内側か外側か、縁から何 px 離れているかを測って、縁をまたぐ幅でなめらかに 0 から 1 へ変わる値にし、25 点の平均で昼と夜の机を混ぜる。机は、波の縁が通りすぎるのに合わせて暗くなります。

机のまわりまで寄ってくる紺色の夜が、すごくきれい。

## 波がボタンや一覧の上を通るところ

波が通るあいだ、ナビ、ボタン、下の一覧は、Shadow DOM の中につくった昼用と夜用の複製を見せています。ページのスタイルシートをすべて読み出し、body や :hover のセレクタを複製用のクラスに書き換えて Shadow DOM に入れ、昼の複製には波のマスクを、夜の複製にはその反転を mask-composite の exclude でかける。波がかかったボタンは、内側が昼の色、外側が夜の色に分かれます。

もとの要素は不透明度を 0 にして残してあり、クリックやホバーはもとの要素が受ける。複製は、毎フレームもとの要素の位置と、ホバーやフォーカスの状態を写しているので、波の途中でボタンに乗っても、ホバーしたときの見た目が出ます。

2 秒の波のあいだも、ページがふだんどおりに触れるままなのがうれしい。
