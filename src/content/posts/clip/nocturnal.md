明晰夢をスクロールで進んでいく、インタラクティブな作品です。湖のほとりのカラスから、水晶玉、教会、ハロウィンの住宅街、街、地球、原子、細胞へと、夢の奥へ入っていきます。

どの場面も、生成りの紙に黒いインクを刷ったような画にそろえてあって、色はテープの黄色がすこし入るくらい。カメラは一度も切れずに、教会の扉の向こうへ抜けたり、街の上空から地球の外へ出たりしながら最後まで続きます。ホイールを回すという、どこにでもある操作だけで、ここまで遠くへ連れていかれるのが楽しい。

## 場面ごとに貼り替わる題

題は、平面のメッシュの頂点を円柱に巻きつけて、ステッカーのように剥がしています。剥がす向きは角から反対の角への対角線で、剥がれ目より先の頂点を円柱に沿わせ、半周を超えたところは折り返して重ねる。裏面には台紙の白をつけてあります。影は、同じ形の平面を、持ち上がった高さに比例して右下へずらし、黒で描いたもの。めくれた角ほど、影が離れて落ちます。

貼るときは、巻く半径を大きいところから小さく絞りながら、貼れた長さを伸ばしていく。貼り終えると、角の持ち上がりと、紙を押しつける動きの 2 つを減衰のあるばねで動かしていて、最後の角がすこし跳ね上がり、浮いたまま落ち着きます。行ごとに剥がす向きを左右で交互にし、すこしずつ遅らせて貼るので、1 行ずつ手で貼っていくように見える。上に貼った半透明のテープも、端のぎざぎざとしわを canvas に描いたものです。題は後処理を終えたフレームの上に重ねて描いていて、場面が変わるたびに前の題が剥がれ、次の題が貼られる。画面の中に、紙を貼る人の手つきがあって、ちょっとうれしい。

## カーソルの跡と、隠れたタグ

カーソルの跡は、GPU で持っているマスクと、2 ピクセルごとに固定した乱数を比べて、画を反転させたものです。マスクは、前のフレームの位置から今の位置までのカプセルを毎フレーム塗り足し、全体をすこしずつ薄めていく。乱数よりマスクが濃いところを、紙とインクの 2 色で明るさを反転した色にします。跡が薄れると、乱数の大きい画素から順にもとへ戻るので、インクが紙に吸われるように消えていく。上に重ねた題も、同じ式で白黒が入れ替わります。

カラスや水晶玉、教会の扉など、夢の中のいくつかのものには、「PRESS AND HOLD TO DISCOVER」というタグが隠してあります。タグは DOM で、ものの中心を毎フレーム画面へ投影した位置に置き、カーソルの最近の位置ごとに CSS の radial-gradient を並べたマスクで切り抜いている。円の半径と消えるまでの時間は GPU の跡と同じ設定から決めていて、時間がたつほど円を小さくするので、インクの跡と重なるところに現れて、いっしょに消えていきます。インクでこすったところから文字が浮かんでくるようで、わくわくする。シャンデリアは、タグの近くにカーソルを置いているあいだ揺れがおさまるので、落ちついて長押しできる。見つけたものは、F キーで開く STORAGE に線画のカードで並び、選んだものが真ん中でワイヤーフレームになって回ります。

## 湖から水晶玉へ

水晶玉の中の景色は、湖の場面を描いた RenderTarget を、ボールレンズの計算で読んだものです。球の各点で、視線を屈折させて中へ入れ、反対側の出口を求めてもう一度屈折させて外へ出し、出ていく向きから読む位置を決める。そのため球の中の景色は上下左右がさかさまになり、外側ほど大きくゆがみます。縁はフレネルで暗くし、照り返しを足してある。

移りはじめは、カメラを球のすぐ外に置き、球がちょうど画面を覆う距離にしています。このときの材質は、画面の座標でそのまま湖を読むので、見ている画は湖のまま変わらない。カメラを引くにつれて、レンズの読み方へ混ぜていきます。湖をのぞいていたはずが、いつのまにか占い師の水晶玉をのぞいていて、どきっとする。

## 教会から先の線

輪郭と、部材と部材の境目の線は、3D の画を描いたあとの後処理で、深度と部材の ID から拾っています。深度の逆数は、平らな面なら画面の座標に対して一次式になります。そのため上下左右の 2 階差分をとると面の内側では 0 になり、輪郭やすき間と折れ目で大きくなる。斜めから見た壁でも線がにじまず、どこでも同じ太さになります。

ID は、石、板、本の 1 冊ずつに乱数を振って頂点に持たせ、色とは別のターゲットへ書き出したもの。隣の画素と ID が違うところにも線を引くので、深度の差がほとんどないところでも、部材が変われば線が入る。教会の壁の石も、棚の本も、1 つずつ別の部材として組んであります。

線は、低い周波数のノイズで拾う位置をずらし、別のノイズで濃さにむらをつけています。ノイズはなめらかに動かさず、1 秒に数回、コマ送りで切り替える。線がこまかく震えて、ペンで引いたように見えるのはこれ。教会と住宅街では、線が何本も集まるところを薄くしてあるので、灰色のかたまりにならない。通路を後ろへ戻るあいだは教会の線を薄くし、水晶玉と台座の線は濃いまま残します。天井の石の目地やかぼちゃの筋のように、材質の中に描いた模様の線も、後処理の線と同じ太さの値で描いている。教会の中も、住宅街も、街の上空も、同じペンで引いたようにそろっていて、気持ちいい。

## 通りの先のアーチ

住宅街の端のアーチの向こうに見える街は、別の RenderTarget に描いた画を、開口に画面の座標で貼ったものです。街のカメラは、通りのカメラの位置をアーチを基準に写して、向きもそのまま渡しているので、のぞく角度に合わせて向こうの街も動く。近いあいだは毎フレーム描き直し、遠いあいだは 1 回描いて止めておきます。カメラが開口を越えたところで、街を直接画面に描くほうへ切り替える。開口の中の画も、くぐったあとの街も同じカメラから描くので、切り替わってもずれない。水晶玉の入りと同じく、別の場面へ移るところを、画面の座標で読むテクスチャをつかってつないであります。くぐった先はそのまま街の上空で、足もとの抜けるようなこわさがある。
