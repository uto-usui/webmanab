映画や CM、アニメーションの録音と音響デザインをしている Dominik Kostolnik さんのサイトです。トップのオレンジのカプセルは、鳴っている音を帯域ごとに測るメーターです。

最初に「ENTER THE EXPERIENCE」というボタンを押して、音つきで入ります。トップのカプセルは音を測るメーター、仕事の内容の帯はフェーダー、フッターは弦の並んだ楽器と、音の現場にあるものがあちこちに置いてあって、どれもさわると音が返ってくる。ヘッドホンをつけて、端から順に試したくなります。

## トップのオレンジのカプセル

カプセルの高さは、鳴っている音を Web Audio の AnalyserNode で周波数ごとに分けた大きさです。7 本が低い音から高い音までの帯域を 1 つずつ受け持っていて、スペクトラムアナライザーと同じつくり。カプセルにカーソルを乗せるとそのカプセルの音がループで鳴り、その音を 7 本で測る。値を追うときにアタックとリリースを分けていて、伸びるときは速く、縮むときはゆっくり落ちていく。何も鳴っていないあいだは解析を止めて、それぞれがゆっくりランダムな高さを行き来します。カーソルを乗せたカプセルからは音符が飛んでいき、その数は、直近でいちばん大きかった音に近づくほど増えて、音が急に立ち上がったところではまとめて出る。

伸び縮みは scaleY でつけているので、そのままだと角の丸みも縦につぶれます。そこで clip-path の角丸を楕円にして、縦の半径を縮める割合で割っておき、縮めたあとで縦と横の半径がそろうようにしている。そのため、どの高さでも角は丸いままです。飾りだと思っていたカプセルが、ほんとうに鳴っている音を測っていて、音の仕事をしている人のサイトらしいなあと思いました。

## カーソル

マウスのカーソルは、OS のカーソルの画像を差し替えてつくっています。その場で組み立てた SVG を data URL にして、CSS の cursor に image-set で等倍と 2 倍を渡している。OS が描くので、どれだけ速く動かしても遅れずについてくる。リンクの上、文章の上、LEISTUNGEN の帯の上で形が変わり、変わるあいだは途中の形の SVG を毎フレーム差し替えつづけます。大きくなる向きの変化には、すこしいきすぎてから戻るイージングをかけています。

リンクの上では、サイトで鳴っている音が急に大きくなると、輪から波紋が外へ広がります。音の大きさはトップのカプセルと同じ AnalyserNode から取っていて、直前までの大きさをはっきり上回ったところで波紋を出す。この波紋も、輪を描きこんだ SVG に差し替えて見せています。OS のカーソルのまま、音に合わせて波打つところまでできるのかと驚きました。

## LEISTUNGEN の 3 本の帯

LEISTUNGEN（仕事の内容）の ORIGINALTON、SOUNDDESIGN、MISCHUNG の帯は、ミキサーのフェーダーです。帯の並びにカーソルが入ると、3 つのループの音が同時に聞こえてくる。ORIGINALTON が足音、SOUNDDESIGN が環境音、MISCHUNG が音楽で、それぞれに StereoPanner をつないで、左寄り、真ん中、右寄りに置いてあります。帯の上でカーソルを横に動かすと、フェーダーはその位置へ毎フレームすこしずつ寄っていき、音量もそれについて変わる。

色の帯は clip-path で右側を切って、音量の位置まで見せています。帯のなかには見出しの文字を暗い色で複製して重ねてあり、帯といっしょに切られるので、フェーダーの位置で文字が白と黒に分かれる。カーソルを乗せると細いつまみと dB の数字が出て、数字は音量の比を対数にとった本物の dB です。帯の真ん中が 0dB、右の端が +6dB、左の端が -∞。動かしはじめると、暗い文字が消えて帯のなかを文字が流れ、その速さも音量に合わせて変わります。

フェーダーが決まった刻みをまたぐたびに鳴るクリックは、音声ファイルをつかわずにその場で合成しています。ごく短いノイズをハイパスに通し、高さのちがう 2 つのバンドパスで響かせる。鳴らすたびに響きの高さをすこしずつずらすので、同じ音がくり返されません。仕事の内容を並べた一覧なのに、触っていると、ミックスの作業をすこしやらせてもらっている気分になります。

## SHOWREEL のカプセル

SHOWREEL まで来ると動画はもう流れていて、7 本のカプセルは、その動画を SVG の clipPath で切り抜いた窓です。窓の上には同じ形の色の層を重ねてあり、色はトップのカプセルの CSS 変数から読んで塗っている。スクロールの区間を長くとってあって、その前半で、窓が真ん中から外へ順に伸び、伸びた割合に合わせて色の層が透けていく。窓の高さもトップのカプセルと同じく、伸びるときは速く、縮むときはゆっくり追います。後半は、両端の余白とカプセルのすき間を真ん中から順に閉じていき、すき間が閉じるのに合わせて角の丸みも減って、画面いっぱいの動画になる。音を測っていたカプセルの形をした窓から、この人が音をつけた作品がのぞくので、見ていてわくわくします。

## いちばん下のフッター

フッターは楽器になっています。横に弦が並んでいて、A を根音にしたペンタトニックマイナーを 2 オクターブ分、左から順に割りふってある。カーソルを乗せて動かすと、ノコギリ波と、その 1 オクターブ下のサイン波を重ねた音が鳴りつづけます。左右の位置で、その下の弦の高さへすべるように移り、上下の位置でローパスフィルターの開き具合が変わって、上にいくほど明るい音になる。音量は動かす速さで決まり、止めると小さくなって消えていく。バンドパスに通したノイズも混ぜ、減衰するノイズでつくったインパルス応答を ConvolverNode に入れて、残響もつけています。

クリックすると、その位置の弦の音を三角波で 1 オクターブ上ではじき、canvas に描いた弦が震える。カーソルの通った跡は金色の線で残り、AnalyserNode から取ったいまの音の波形で線と直角の向きへずらしているので、オシロスコープのように揺れます。フッターがはじめて画面に入ったときは、カーソルを追う丸がひとりでに左から右へ動いて弦をはじいて見せ、マウスを動かすとすぐに止まります。ここまでは用意された音を鳴らしたり混ぜたりしてきて、最後のフッターでは、音の高さも明るさもじぶんの手で決めて弾けるのが、うれしい。
