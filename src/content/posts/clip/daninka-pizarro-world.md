チリのサンティアゴにいる、絵を描き、デザインして、コードを書く Daninka Pizarro さんのポートフォリオです。経歴、得意なこと、仕事の進め方、事例を、じぶんの頭の中の世界として、本人がスクロールで歩いて案内してくれます。

生成りの紙に青いインクの線で、3D の本人も、まわりの木や看板も、同じ版画のような線で描かれていて、歩いていくのが楽しい。ライブラリをつかわず、WebGL2 と Canvas 2D を 1 枚の HTML に自前で書いているのにも、おどろきました。

## 頭が開いて本人が出てくるところ

読み込みが終わると出てくる大きな頭は、WebGL で描いている本人の人物を、頭に寄せたカメラで一度だけ描いて、別の canvas に写した静止画です。同じ静止画を 2 枚重ね、ジグザグの線で上下に分ける clip-path をかけて、上の 1 枚を Web Animations API で回して開けている。

開いた頭から出てくる小さな本人も、本編と同じカメラで一度だけ描いた静止画で、頭の切り口のあたりで小さくした状態から、元の位置と大きさへ戻していきます。戻りきった位置は、本編で WebGL の人物が立つ位置と重なるので、そこで静止画を外すと、本人は同じ場所に立ったまま WebGL の canvas に入れ替わる。

頭のふたがぱかっと開く絵本のような入りから、そのまま本編の世界へ降りてくるのがかわいい。

## 本人の陰の斜線

人物の陰は、フラグメントシェーダーで画面の座標に線を引いてつくっています。光の向きとの内積、色の明るさ、輪郭に近いほど暗くするリムの項から暗さを出し、暗さに合わせて、斜め 2 方向と縦の 3 組の線を順に足していく。明るいところは紙のまま、すこし暗くなると 1 方向の斜線、さらに暗くなると線が交わり、いちばん暗いところは塗りつぶしになります。

斜めの 2 組は、面の法線の向きに合わせて互いに逆へずらしてあるので、線が体の丸みに沿って曲がる。顔は陰を薄くして、眉や目、口、ほくろのような、テクスチャの暗いところを濃くしてあるので、表情がつぶれません。髪には、波のようにゆらした線のぶんだけ暗さを引いて、明るい筋を入れている。

線の位置は、1 秒に 15 回、3 通りの位置を順に切り替えるラインボイルにしています。背景の Canvas 2D の線画も、同じ周期で同じように切り替えている。

3D なのに、版画の人物が紙の上を歩いているように見えて、うれしい。

## 本人のふちの線

ふちの線は、人物を描くときに、色とは別のテクスチャへ法線、深度、メッシュの番号を書き出しておき、2 回目のパスで上下左右の画素と比べて引いています。メッシュの番号が変わるところには、人物の外側のふちや、上着と袖、袖口の境目の線が入る。同じメッシュの中でも、法線が急に変わる折れ目や、深度が飛ぶ手前と奥の重なりには線が入ります。

顔の中だけはこの線をほとんど消してあるので、鼻や頬に余計な線が出ない。色も、比べるための法線や深度も、値ノイズですこしずらした位置から読んでいて、そのずらし方も陰の斜線と同じ周期で切り替えています。

顔に余計な線がなくて、表情がすっきりしているのがいい。

## PATH の線画が引かれていくところ

PATH の駅にある、物干しの綱と柱、クレヨンの絵、絵の具の画板、タブレット、ノートパソコンの線画は、どれも線ごとに点の並びと長さを持っています。本人が近づくほど大きくなる割合を、全部の線をつないだ長さに掛けて、その長さまでを先頭の線から順に引き、引きかけのところにはペン先の丸を置く。線が半分ほど引けたところからは、紙の色の塗りを重ねて、後ろの線を隠していきます。

割合は本人の位置だけで決まるので、戻る向きに歩けば、引いた線が逆の順に消えていく。

歩く速さで描く速さが変わって、じぶんで線を引いているようで楽しい。

## PATH で本人が育つところ

PATH の駅を歩いていくと、物干しの柱のあたりで本人は子どもになり、クレヨンの絵、絵の具の画板、タブレットの手前を越えるたびに 1 段ずつ育って、今の姿に戻ります。段ごとに、人物全体の大きさ、巻き毛の長さと幅、お団子の有無と位置を替えている。子どものころは巻き毛を縦に縮めて短くし、次の段はさらに短くしてお団子を後ろに載せ、その次は巻き毛を消してお団子だけにします。脚のテクスチャに描いてある天使と枝のタトゥーは、今の姿に戻るまで外してある。戻る向きに歩けば、また小さくなります。

段が替わる瞬間は、人物をすこし大きくはずませ、本人のまわりに、広がりながら薄れていくインクの輪を Canvas 2D で描いている。

子どものころの写真の前を小さな本人が通りすぎて、タブレットのところまで来ると、タトゥーの入った今の本人になっている。いっしょに歩いているうちに、この人のことをすこし知った気になれて、すてきです。
