# a11y の追跡一覧

旧サイトから引き継いだ a11y の違反と、その状態の一覧です。リニューアルの計画のときの表をここに移し、直したら状態の欄を書き換えます。件数の基準は `test/a11y/baseline.json`（ページ）と `test/a11y/baseline-catalog.json`（部品のカタログ）にあり、`pnpm test:a11y` で比べます。基準を変えたときは、そのファイルの `changes` に理由を書きます。

分類は 08 の 2.5 と同じです。

- (1) 見た目が変わらない直し
- (2) キーボード操作のときや、利用者が設定したときだけ見える直し
- (3) 誰にでも見た目が変わる直し。作者が直すと決めたものだけ入れる

## メモ

- A11Y-19 は、08 の案ではリンクごとに見えない文字を足すことにしていました。本文の HTML はフィード（RSS / Atom）と検索の索引にもそのまま入るので、文字は足さず、レイアウトに 1 つだけ置いた hidden の要素を `aria-describedby` で指しています。
- A11Y-16 の枠は `src/styles/foundation/base/_base.scss` にあります。部品の中で `outline-offset` を変えているもの（コードの copy ボタン）は、部品の指定が勝ちます。
